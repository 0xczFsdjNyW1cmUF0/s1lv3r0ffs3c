# PortSwigger: обход логина через SQLi

**Лаба:** SQL injection vulnerability allowing login bypass

## Суть

Обработчик формы входа подставляет имя пользователя и пароль в SQL-запрос:

```sql
SELECT * FROM users WHERE username = '<u>' AND password = '<p>'
```

## Решение

В username:

```
administrator'--
```

Условие проверки пароля попадает в комментарий, и запрос находит администратора только по имени. Вход под administrator, лаба закрыта.

## Заметка

Сначала писал `--` вплотную к кавычке: запрос не срабатывал, сервер молчал. Десять минут подозревал WAF, но проблема была в пробеле. Это требование зависит от СУБД: в MySQL после `--` нужен пробельный или управляющий символ; там же можно использовать `#` для однострочного комментария.
