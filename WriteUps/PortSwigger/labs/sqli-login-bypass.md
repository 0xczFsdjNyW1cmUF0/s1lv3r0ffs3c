# PortSwigger: обход логина через SQLi

**Лаба:** SQL injection vulnerability allowing login bypass

## Суть

Форма логина собирает запрос на строке:

```sql
SELECT * FROM users WHERE username = '<u>' AND password = '<p>'
```

## Решение

В username:

```
administrator'--
```

Пароль уходит в комментарий, запрос находит админа по одному имени. Вход под administrator, лаба закрыта.

## Заметка

Нюанс, на котором сам сначала споткнулся: после `--` нужен пробел (или ставить `#` для MySQL). Писал `--` впритык к кавычке — запрос не собирался, сервер молчал. Десять минут думал, что там WAF. Не WAF. Пробел.
