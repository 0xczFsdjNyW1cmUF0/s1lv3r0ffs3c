# PortSwigger: SQLi в WHERE, скрытые данные

**Лаба:** SQL injection vulnerability in WHERE clause allowing retrieval of hidden data
**Решал руками, без sqlmap**

## Суть

В каталоге товаров значение фильтра по категории подставляется прямо в SQL-запрос:

```sql
SELECT * FROM products WHERE category = '<ввод>' AND released = 1
```

Ввод никак не экранируется.

## Решение

В поле категории:

```
' OR 1=1--
```

Условие `released = 1` попадает в комментарий, а `OR 1=1` делает условие выборки истинным для всех строк. Возвращается весь каталог, включая неопубликованные товары. Лаба засчитана.

## Заметка

Задача лабы — увидеть скрытые записи, а не извлечь пользователей через UNION. Я начал усложнять решение и дошёл до попытки загрузить шелл, хотя хватало изменить условие выборки и закомментировать конец запроса.
