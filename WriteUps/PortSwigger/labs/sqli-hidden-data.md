# PortSwigger: SQLi в WHERE, скрытые данные

**Лаба:** SQL injection vulnerability in WHERE clause allowing retrieval of hidden data
**Решал руками, без sqlmap**

## Суть

Каталог товаров, фильтр по категории подставляется прямо в запрос:

```sql
SELECT * FROM products WHERE category = '<ввод>' AND released = 1
```

Ввод никак не экранируется.

## Решение

В поле категории:

```
' OR 1=1--
```

`released = 1` улетает в комментарий, возвращается весь каталог, включая невыпущенные товары. Лаба засчитана.

## Заметка

Тут легко сразу пихать UNION и тянуть users. Не надо: задача лабы — увидеть скрытые записи, минимальный вектор — 12 символов. Сподвигнул себя заливать шелл, хотя достаточно было закомментить конец запроса. Усложняешь — проверь, не хватит ли скромнее.
