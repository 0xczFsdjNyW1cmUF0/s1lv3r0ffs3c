# Squid Game: разбор пяти документов с макросами

**Машина:** [Squid Game](https://tryhackme.com/room/squidgameroom) (hard, blue team)
**Суть:** пять вредоносных .doc с VBA-макросами, от простой обфускации до шеллкода. Разбираем каждый документ.

Инструменты: `oledump.py`, `olevba`, `oletimes`, `vipermonkey`, ANY.RUN (песочница) и CyberChef. Файлы забираются с машины по scp/sftp.

## Стадия 1 — разогрев

`oledump.py attacker1.doc` показывает макрос в стриме 8 (`-s 8 -v` достаёт код). Полезная нагрузка — base64 в квадратных скобках; в коде есть replace-таблица, где `[` маппится на `A`. Делаем замену в CyberChef → base64 decode → чистый PS-скрипт со сливом на C2. Метаданные (автор, телефон, время создания) добираются `exiftool` и `oletimes`. Метаданные нужны для части вопросов комнаты.

## Стадия 2 — потяжелее

Макросов больше (стримы 12-16). Команды в стримах перевёрнуты задом наперёд: `oledump -s a -S | grep fun | rev` выдаёт `cmd /k cscript.exe C:\ProgramData\pin.vbs`. DLL-загрузчик качает пять DLL в `C:\ProgramData` и запускает их с задержкой. Финт с `-i` на oledump — без него не видно размер compiled-кода, а на него есть вопрос.

## Стадия 3 — certutil

Классика: макрос собирает `certutil` из обфусцированных кусков (`tutil` + префикс), качает бинарник с `http://<c2>/....php?l=...cab`. URL не виден в строках — `grep http` пусто. Достаётся только эмуляцией: `vmonkey attacker3.doc` прогоняет макрос и печатает реальные вызовы с параметрами. Через какой стрим исполняется — Yara-правило прямо в oledump: `--yara=#s#1.exe` показывает совпадение.

## Стадия 4 — XOR

```vb
CreateObject(XORI(Hextostring("020A271C..."), Hextostring("51624270")))
```

Строка декодируется операцией XOR с ключом из кода. CyberChef: from hex → XOR → получаем имя COM-объекта. Ручная деобфускация по следам в коде, недоступный домен загрузки мешает увидеть дальнейшее поведение в песочнице.

## Стадия 5 — шеллкод

Base64 в справочном тексте формы → после replace-чистки → base64 → gunzip → ещё один base64 → XOR с десятичным ключом 35. На выходе шеллкод, смотрим его `scdbgc`:

```
scdbgc /f shellcode.dat -s -1
```

## Заметка

ANY.RUN помогает наблюдать поведение документа в песочнице, а vmonkey эмулирует VBA. Если внешние ресурсы недоступны или эмулятор не поддерживает нужный вызов, остаётся разбирать макрос и извлекать нагрузку вручную.
