# FAT32 Analysis: форензика файловой системы с нуля

**Машина:** [FAT32 Analysis](https://tryhackme.com/room/fat32analysis) (hard, DFIR)
**Инструменты:** HxD, Autopsy 4.21. Всё на Windows-лаборатории, образы в `C:\FAT32_analysis\`.

## Зачем вообще FAT32

FAT32 не хранит права доступа к отдельным файлам и не ведёт журнал изменений. Доступ к самому носителю при этом может ограничивать ОС. В комнате разбираем образ диска в HxD.

## Структура тома

```
Reserved Area → FAT Area (FAT1 + FAT2) → Data Area
```

Boot sector (сигнатура `55 AA` в конце) отдаёт метаданные тома: bytes per sector, sectors per cluster, сколько reserved-секторов, сколько FAT-таблиц, размер каждой. От этих чисел считаются все оффсеты — без них никуда. Порядок little endian, с этим спотыкаешься раз пять, пока не привыкнешь.

## Что искал руками

- **Скрытые файлы.** Байт атрибутов SFN-записи на оффсете `0x0B`: `0x02` — hidden. FAT32 не хранит permissions для этого атрибута; изменить его может тот, у кого есть доступ на запись к носителю.
- **Удалённые файлы.** При удалении содержимое не стирается — первый байт имени меняется на `0xE5`. Контент лежит в кластерах до перезаписи. Для восстановления ищем E5-запись и начальный кластер. При удалении цепочка в FAT обычно освобождается, поэтому восстановить её напрямую удаётся не всегда; фрагментация усложняет поиск данных.
- **Таймстомпинг.** FAT хранит три метки: создание, изменение, последний доступ. Необычный порядок меток — повод проверить файл, но не доказательство подмены: при копировании дата создания может оказаться позже даты изменения. Нужно учитывать точность меток FAT и то, как система их обновляет. Autopsy помогает сопоставить события на таймлайне.
- **Слэк-спейс и карвинг.** Неиспользуемая часть последнего выделенного кластера может содержать остаточные данные. Из восстановленных скриптов отдельно извлекал и декодировал base64-строки.

## Заметка

Удаление в FAT32 меняет запись каталога и освобождает кластеры, но не гарантирует стирания содержимого. Возможность восстановления зависит от перезаписи данных и сохранности сведений об их расположении.
