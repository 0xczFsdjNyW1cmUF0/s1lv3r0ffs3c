# W1seGuy: known plaintext против XOR

**Машина:** [W1seGuy](https://tryhackme.com/room/w1seguy) (easy, crypto)
**Суть:** сервер отдаёт XOR-шифрованный флаг ключом длиной 5. Знаем формат флага — восстанавливаем ключ.

## Разбор

К сервису на 1337 подключаешься — получаешь hex-строку. В исходнике видно: флаг XOR'ится посимвольно с ключом из 5 символов (буквы + цифры), ключ рандомится при каждом запуске сервера. Значит, чужой флаг с гугла не подойдёт — решается только свой инстанс.

## Атака

XOR обратим сам себе: `C ⊕ P = K`. Формат флага известен — `THM{...}`, значит:

- первые 4 байта шифротекста ⊕ `THM{` = первые 4 символа ключа
- последний байт ⊕ `}` = пятый символ ключа (длина флага кратна 5 — позиция сходится)

Пятый символ можно и забрутить по словарю из 62 вариантов, если длина не кратна. Собираем ключ, прогоняем `decrypt_xor` — флаг. Второй флаг — просто вводим найденный ключ на сервере.

```python
def derive(ct_hex, known, start):
    ct = bytes.fromhex(ct_hex)
    return ''.join(chr(ct[start+i] ^ ord(known[i])) for i in range(len(known)))

key = derive(ct, 'THM{', 0) + derive(ct, '}', len(bytes.fromhex(ct))-1)
```

## Заметка

Три вывода, которые пригодились потом везде. Первый: known plaintext — рабочая лошадка против любого XOR. Второй: повторяющийся короткий ключ — это не шифр, это шум. Третий: сначала читать исходник — там длина ключа и алфавит, это экономит час гаданий.
