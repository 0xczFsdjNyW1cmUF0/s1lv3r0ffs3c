# macOS Forensics: Artefacts — что macOS помнит о тебе

**Машина:** [macOS Forensics: Artefacts](https://tryhackme.com/room/macosforensicsartefacts) (hard, DFIR)
**Формат:** macOS-образ (`mac-disk.img`) анализируется с линуксовой VM. Монтирование APFS:

```bash
apfs-fuse -v 4 mac-disk.img ~/mac   # -v 4 — именно Data-том
```

## Артефакты по полочкам

- **Plist.** XML читается через `cat` или другой текстовый просмотрщик, бинарные plist — парсером, например `plutil -p` на macOS. Возможности `plistutil -p` в Linux стоит проверить для установленной версии.
- **SQLite.** В базах можно найти историю чатов, браузера и сведения об использовании приложений. DB Browser для ручного разбора, APOLLO — для таймлайна.
- **Терминал.** `~/.zsh_history` — сохранённая история команд. Объём и порядок записей зависят от настроек zsh и работы параллельных сессий.
- **ASL-логи** в `/private/var/log/asl/` — системные сообщения, в том числе связанные со входом в систему. Это отдельный источник, не сами файлы utmp/wtmp. Для разбора в Linux используется mac_apt; набор доступных записей зависит от версии macOS.
- **Использование приложений** — `knowledgeC.db` (пользовательский: `~/Library/Application Support/Knowledge/`, системный: `/private/var/db/CoreDuet/`): старт/стоп приложений, активность.
- **Файловая активность** — FSEvents: создание, удаление, rename, монтирование томов.
- **USB и монтированные образы** — `com.apple.finder.plist`, ключ `FXDesktopVolumesPositions`: флешки и DMG, которые видел Finder.
- **Bluetooth-аудио** — тоже из knowledgeC.db, удобно через модуль APOLLO `knowledge_audio_bluetooth_connected`.

## Заметка

Историю команд, запусков приложений и подключений стоит сопоставлять между несколькими источниками. Наличие артефактов и глубина истории зависят от версии macOS, настроек и сохранности образа.
