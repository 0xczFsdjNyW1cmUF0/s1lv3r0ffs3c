# HTTP/2 Request Smuggling: десинк через даунгрейд

**Машина:** [HTTP/2 Request Smuggling](https://tryhackme.com/room/http2requestsmuggling) (hard, web)
**Суть:** HTTP/2 задаёт границы данных фреймами. При переводе запросов в HTTP/1.1 ошибки проверки длины и заголовков могут привести к request smuggling.

## Откуда берётся рассинхронизация HTTP/1

В HTTP/1 граница тела запроса задаётся двумя способами: `Content-Length` и `Transfer-Encoding: chunked`. Если фронт и бэкенд понимают их по-разному — один запрос превращается в два. Классика десинка.

## Почему HTTP/2 — и как всё равно ломается

В H2 границы данных заданы фреймами. Если фронтенд принимает H2, а бэкенду пересылает H1, он сам собирает HTTP/1.1-запрос. Ошибки при таком преобразовании могут рассинхронизировать обработку запросов.

Ключевой трюк: H2-запрос несёт `Content-Length` «для совместимости». Ставим `Content-Length: 0`, а в тело кладём полноценный HTTP/1-запрос:

```
POST / HTTP/2
content-length: 0

GET /admin HTTP/1.1
Host: localhost
```

Уязвимый фронтенд принимает тело из DATA-фреймов, но при переводе в H1 сохраняет неверный Content-Length. Бэкенд читает: тела нет (CL 0), дальше в потоке — новый запрос. Фронтенд получил эти байты как тело POST, а бэкенд интерпретировал `/admin` как отдельный запрос.

## h2c

Отдельный вариант — HTTP/2 cleartext. Если прокси пропускает `Upgrade: h2c` к бэкенду и после переключения туннелирует соединение без прежних HTTP-проверок, последующие запросы могут обойти логику фронтенда.

## Как обнаружить

Прямых IoC почти нет: десинк живёт в разнице двух парсеров, в access log это один нормальный запрос. Ловится на уровне фреймов: `content-length: 0` при непустых DATA, `Upgrade: h2c` от клиента, ошибки бэкенда про content length при чистом фронте. Нужны исправления прокси, проверка соответствия Content-Length длине DATA и безопасное преобразование заголовков при даунгрейде. Сам по себе H1 на бэкенде проблему не устраняет.

## Заметка

При тестировании H2-прокси стоит отдельно проверять преобразование запросов в H1 и обработку h2c Upgrade. Это разные механизмы, хотя оба могут дать обход проверок фронтенда.
