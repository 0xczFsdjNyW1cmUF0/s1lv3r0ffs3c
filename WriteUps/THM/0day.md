# 0day: Shellshock и kernel 3.13

**Машина:** [0day](https://tryhackme.com/room/0day) (medium, Linux)
**Цепочка:** nikto → Shellshock в CGI → шелл → overlayfs → root.

## Футхолд

Открыты 22 и 80. Подсказка комнаты честная: «hidden directories are a rabbit hole». Гобустер пускать можно, но толку нет. nikto сразу показывает уязвимость к Shellshock на `/cgi-bin/test.cgi`.

Эксплуатация — одной строкой, без метасплойта:

```bash
curl -A "() { :; }; echo Content-Type: text/html; echo; /bin/bash -c 'id'" http://0day.thm/cgi-bin/test.cgi
```

Bash исполняет трейлер функции из переменной окружения (User-Agent прокидывается в окружение CGI-скрипта). Дальше меняем команду на реверс-шелл.

## Привилегии

Ос — Ubuntu 14.04.1, ядро 3.13.0. Кернел-эксплойты — крайняя мера, но здесь это и есть задуманный путь. Берём overlayfs local privesc (37292), тащим на машину, компилим.

Первая попытка сборки падает: в этой убунте PATH кривой, `gcc` не находит `cc1`. Лечится классикой:

```bash
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

Дальше компиляция и запуск проходят, root.

## Заметка

Обе уязвимости — из-за одного и того же: систему не обновляли годами. Про kernel-exploit важно не забывать обратное: он жёстко привязан к версии ядра и дистрибутиву и может положить машину крешей даже после успеха. Перед запуском — читать сорс, иметь в виду, что это пушка последнего выстрела, а не рабочая лошадка.
