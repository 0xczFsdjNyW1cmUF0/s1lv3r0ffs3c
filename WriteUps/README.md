# WriteUps

Разборы задач и уязвимостей — чтобы не забыть детали и не проходить один и тот же путь дважды.

| Раздел | Что внутри |
|---|---|
| [`THM/`](./THM) | 20 разборов машин TryHackMe — все hard из пройденных + жёсткие medium (AD, potato-уязвимости, crypto, десериализация, Hacker Holidays 2026) |
| [`PortSwigger/`](./PortSwigger) | Прогресс по Web Security Academy (273 лабы, помесячно сверяется) + 8 разборов лаб, включая все 5 expert |

Формат разборов одинаковый: **суть → вектор → заметка** (на чём ловился сам или что запомнилось), шаблон — [`_templates/writeup.md`](../_templates/writeup.md). Где у техники есть синяя сторона — короткая секция «Как поймать»: что торчит в логах, на какие события алертить. Флагов нет — только подход.
