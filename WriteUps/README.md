# WriteUps

Разборы задач и уязвимостей — чтобы не забыть детали и не проходить один и тот же путь дважды.

| Раздел | Что внутри |
|---|---|
| [`THM/`](./THM) | 12 разборов машин TryHackMe — все hard из пройденных + жёсткие medium (AD, potato-уязвимости, crypto, десериализация, Hacker Holidays 2026) |
| [`PortSwigger/`](./PortSwigger) | Прогресс по Web Security Academy (273 лабы, помесячно сверяется) + 8 разборов лаб, включая все 5 expert |

Формат разборов одинаковый: **суть → вектор → заметка** (на чём ловился сам или что запомнилось). Флагов нет — только подход.
