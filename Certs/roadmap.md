## Очередь

1. **Mystery labs — 2/5.** Задачи без заранее известного типа уязвимости. Отдельно нужно подтянуть темы: CSRF (1/10), XSS (2/16), HTTP request smuggling (2/15), web cache poisoning (1/9), prototype pollution (0/9). Выбранные разборы — в [labs](../WriteUps/PortSwigger/labs/).
2. **Practice exam.** Пройти после Mystery labs, когда разберусь со слабыми темами.
3. **Запись на BSCP.** Записаться после пробного экзамена. По текущему списку подготовки остались Mystery labs и Practice exam.
