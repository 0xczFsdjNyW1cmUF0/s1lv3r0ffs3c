# Certs

Раздел, который можно показать HR'у или закинуть в резюме. Всё подтверждено документами — ничего лишнего.

## Содержание

- [`education.md`](./education.md) — вся пройденная ИБ-школа за 3 года одной таблицей + CTF
- [`TryHackMe/`](./TryHackMe) — дамп профиля (329 комнат, 32 бейджа), скрин статистики, список комнат
- [`Stepik/`](./Stepik) — Белый Хакер, Противодействие кибератакам, Правовые основы (ДВФУ)
- [`Yandex/`](./Yandex) — веб-пентест (расширенный), 7 месяцев
- [`CyberYozh/`](./CyberYozh) — Advanced Cyber Labs CTF
- [`AcademyIT/`](./AcademyIT) — Пентестер: этичный хакинг

## Формат

Для каждой школы — отдельная папка: диплом (PDF/PNG/JPG) + короткий README: что, где, когда.
