# Certs

Раздел, который можно показать HR'у или закинуть в резюме, если вдруг потребуется.
Всё, что пройдено и подтверждено официально: сертификат, диплом, завершённый курс.

## Содержание

- `education.md` — вся пройденная ИБ-школа одной таблицей + CTF.
- **Stepik** — `Stepik/`
- **Yandex** — `Yandex/`
- **TryHackMe** — `TryHackMe/`

Дальше пополняется по мере прохождения. В планах — экзамен PortSwigger (BSCP), но до него ещё идти и идти, так что появится не скоро.

## Формат

Для каждого — отдельная папка. Внутри:
- PDF, если выдали
- скриншоты прогресса / бейджей
- краткий `.md`: что, где, когда

## Зачем

Чтобы держать все подтверждения в одном месте. Без лишнего шума — просто факты.
