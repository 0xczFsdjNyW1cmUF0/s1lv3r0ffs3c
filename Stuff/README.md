# Stuff

Шпаргалки, инструменты и ссылки для лаб и CTF.

- `reverse-shells.md` — reverse shell одной строкой и настройка интерактивного терминала.
- `sqli.md` — шпаргалка по инъекциям под разные СУБД.
- `file-upload.md` — обходы проверок при загрузке файлов.
- `ssti.md` — определение движка шаблонов и типовые пейлоады.
- `web-checklist.md` — базовый чеклист для веб-приложения.
- `resources.md` — плагины Burp, словари, рецепты CyberChef и рабочие ссылки.

## scripts/ — вспомогательные скрипты

- `revshell.sh` — генератор реверс-шеллов (bash/sh/python/php/powershell/nc/mkfifo/java)
- `tty.sh` — настройка интерактивного терминала в шелле
- `lin-quick.sh` — разведка Linux после получения шелла: sudo, SUID, capabilities, учётные данные в конфигах, cron, docker
- `win-quick.ps1` — разведка Windows: привилегии, уязвимые сервисы, другие учётные данные
- `ad-attack.sh` — обвязка kerbrute/impacket: userenum → ASREPRoast → spray → dcsync
- `webshell.py` — генерирует php/aspx-шелл с управлением через заголовок `X-CMD`; команды не передаются в GET-параметрах
- `ferox-wrap.py` — перебор каталогов с автоматическим обходом найденных подкаталогов
- `pspy-local.py` — отслеживает доступные для наблюдения запуски процессов, в том числе от root, без root-прав (аналог pspy)
- `docker-escape.sh` — разведка контейнера: capabilities, docker.sock, монтирования хоста, k8s-токен
- `git-dumper.sh` — скачивает .git с веб-сервера и извлекает удалённые файлы из истории
