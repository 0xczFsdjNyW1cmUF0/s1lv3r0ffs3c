# Stuff

Рабочий ящик с инструментами. Всё, что реально выручало в лабах и тасках — без воды и без «awesome-списков», скопированных непонятно откуда.

- `reverse-shells.md` — шеллы одной строкой + апгрейд до нормального tty.
- `sqli.md` — шпаргалка по инъекциям под разные СУБД.
- `file-upload.md` — как пробивать загрузку файлов.
- `ssti.md` — определение движка шаблонов и типовые пейлоады.
- `web-checklist.md` — базовый чеклист для веб-точки.

Правило простое: сюда попадает только то, что сам проверял руками. Не завалено — пополняется по мере прохождения лаб.
