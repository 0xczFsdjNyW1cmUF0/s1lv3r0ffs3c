## Разборы

Конспекты публичных разборов: цепочка атаки и детали, к которым стоит вернуться. Это не отчёты о моём прохождении. Авторы и ссылки на оригиналы указаны в самих заметках и в [readings.md](./readings.md). Флаги не публикую.

- **S7** — [GhostBusters](./tasks/ghostbusters.md): Ghost CMS, SQLi → RCE через тему → эксплуатация уязвимости ядра → служба выдачи флагов
- **S6** — [SaveWalterWhite](./tasks/savewalterwhite.md): LFI → RFI/RCE → sudo-скрипты → Borg с парольной фразой в MySQL → привилегированный контейнер
- [Bank](./tasks/bank.md) — сезон не указан в источнике: Windows DC → Server Operators → PIN-код как ключ HMAC → ProFTPD → docker.sock
- **S5** — [PigeonsRevenge](./tasks/pigeons-revenge.md): port knocking по подсказке в метаданных → бэкдор Webmin → ligolo → инъекция команд через переменную окружения с обходом фильтра табуляцией
